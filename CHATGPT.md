# AXIOM for ChatGPT

The separate [ChatGPT adapter](chatgpt/README.md) provides explicit operating
instructions, checkpoint restoration, local validation tools, and behavioral
probe procedures. Start with [the activation artifact](chatgpt/AXIOM_BOOTSTRAP.md).

The original Claude Code installer, hooks, memory files, and research documents
are preserved. They are not the activation path for native ChatGPT. See the
adapter's [compatibility limits](chatgpt/COMPATIBILITY.md) and
[validation record](chatgpt/VALIDATION.md) before making persistence claims.
